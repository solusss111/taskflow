# TaskFlow

Консольный менеджер задач на Python. Позволяет создавать задачи со сроком выполнения, менять их статус, фильтровать и находить просроченные. Задачи сохраняются в JSON-файл и не теряются между запусками.

## Возможности

- создание задачи с названием и необязательным сроком (`ГГГГ-ММ-ДД`);
- просмотр всех задач в виде таблицы;
- смена статуса на любой из `todo`, `in_progress`, `done`;
- удаление задачи с подтверждением;
- фильтр задач по статусу;
- список просроченных задач (срок прошёл, а задача не выполнена);
- автоматическое сохранение в `data/tasks.json` после каждого изменения.

## Требования

- Python 3.10 или новее
- зависимости из `requirements.txt` (`tabulate`, `pytest`)

## Установка

```bash
git clone https://github.com/solusss111/taskflow.git
cd taskflow
python -m venv venv
```

Активируйте виртуальное окружение:

```bash
# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Откроется меню:

```
========== TaskFlow ==========

1. Создать задачу
2. Показать все задачи
3. Изменить статус задачи
4. Удалить задачу
5. Найти задачи по статусу
6. Показать просроченные задачи

0. Выйти
```

Выход — пункт `0` или `Ctrl+C`.

## Хранение данных

Задачи хранятся в `data/tasks.json`. Файл создаётся автоматически при первом изменении, папка `data/` не попадает в git.

```json
{
  "next_id": 3,
  "tasks": [
    {
      "id": 1,
      "title": "Купить молоко",
      "due_date": "2030-01-01",
      "status": "todo"
    },
    {
      "id": 2,
      "title": "Без срока",
      "due_date": null,
      "status": "done"
    }
  ]
}
```

`next_id` хранится отдельно, чтобы ID удалённых задач не выдавались повторно. Запись идёт через временный файл, поэтому сбой во время сохранения не повредит существующие данные. Если файл всё же окажется повреждён, программа сообщит об ошибке и не запустится, чтобы не перезаписать его пустым списком.

## Структура проекта

```
taskflow/
├── main.py          # консольное меню и взаимодействие с пользователем
├── board.py         # TaskBoard — список задач и операции над ним
├── models.py        # Task — модель задачи, валидация, (де)сериализация
├── storage.py       # сохранение и загрузка доски из JSON
├── data/            # tasks.json (создаётся автоматически)
├── tests/           # тесты pytest
├── pytest.ini
└── requirements.txt
```

## Тесты

```bash
pytest
```

Тесты не трогают настоящий `data/tasks.json`: файлы создаются во временной папке `.pytest_tmp/`.
